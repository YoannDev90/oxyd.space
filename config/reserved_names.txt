# Reserved subdomain names for oxyd.space
#
# Matching rules:
#   - One name per line, lines starting with # are ignored.
#   - Case-insensitive match against SINGLE-LABEL registrations only:
#       "nextcloud" blocks nextcloud.oxyd.space
#       but NOT nextcloud.john.oxyd.space (personal instances are fine).
#
# Rationale: prevent brand/service impersonation and phishing on top-level
# names that look official. Self-hosters should nest under their own name:
# servicename.username.oxyd.space
